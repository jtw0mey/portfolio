Premier League xG Pipeline

End-to-End Data Engineering Project

Project Overview

This was my first end-to-end data engineering project where I built a complete pipeline to collect football data from the web (Understat). I loaded the raw data into a DuckDB warehouse, transformed and modeled it using dbt, tested for missing data, and built an interactive Streamlit dashboard to display the analytics.

  • 🚀 Live Interactive Dashboard
  • 💻 GitHub Repository

How the Pipeline Works

  • Extract: Uses Python ('AsyncIO' and 'aiohttp') to collect player and team performance data from Understat into raw CSV files.
  • Ingest (dbt Seeds): Uses dbt seeds to automatically load raw CSV files straight into a DuckDB database.
  • Transform (dbt Models): Uses SQL in dbt to clean data types, combine multiple seasons, and build dynamic analytics models (staging and summary tables).
  • Data Quality Testing: Runs automated dbt tests to catch missing values (`not_null`) and ensure database tables stay clean and accurate.
  • Dashboard: Connects DuckDB directly to Streamlit, rendering fast interactive charts and data tables powered by Plotly.
  • Automate: Scheduled via GitHub Actions to automatically re-run the pipeline every day at 04:00 UTC so the data stays updated hands-free.

Tech Stack

  • Language: Python 3.11
  • Database & Modeling: DuckDB, dbt (data build tool), SQL
  • Data Processing & Collection: Pandas, 'understat', 'AsyncIO', 'aiohttp'
  • Dashboard & Visualization: Streamlit, Plotly
  • Testing & Automation: dbt test, pytest, GitHub Actions
  • Hosting: Streamlit Community Cloud
